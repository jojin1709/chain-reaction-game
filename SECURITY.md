# Security Policy

## Supported Versions

Security updates are applied directly to the `main` branch and deployed to production.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **Chain Reaction**, please do not report it publicly via GitHub issues.

Instead, please contact the maintainer directly:

- **Maintainer**: JOJIN JOHN
- **Contact**: Reach out via [LinkedIn](https://www.linkedin.com/in/jojin-john/) or open a private report.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Impact assessment.

We will acknowledge receipt of your vulnerability report promptly and work on a fix as quickly as possible.
